# 📊 Power BI Data Analysis Dashboard

## 📌 Project Overview

This project is an interactive Power BI dashboard designed to analyze business data and present key performance indicators through clear and interactive visualizations.

The dashboard helps users understand overall performance, identify trends, compare categories, and make data-driven decisions.

## 🛠️ Tools & Technologies

* Power BI
* Microsoft Excel
* Data Cleaning & Transformation
* DAX
* Data Visualization

## 📈 Dashboard Features

* Interactive KPI cards
* Trend analysis
* Category-wise analysis
* Comparative visualizations
* Filters and slicers
* Interactive charts and graphs
* Business performance overview

## 🎯 Key Objectives

* Analyze important business metrics
* Identify trends and patterns
* Compare performance across different categories
* Convert raw data into meaningful insights
* Build an interactive business intelligence dashboard
